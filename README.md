# APHA-AI-Fairness
APHA-AI-Fairness

This repository contains the data, Python code, visualizations, and references for my research project evaluating racial fairness, predictive accuracy, and calibration in ChatGPT-based clinical predictions.

The study compares ChatGPT Basic and Pro, with and without race as an input, against traditional logistic regression and three bias-mitigation methods: Reweighing, Prejudice Remover, and Equalized Odds.

Repository Structure

Data./ — Four CSV datasets containing patient information, true labels, and ChatGPT predictions across access tiers and race-input conditions.

Images./ — Visualizations of model performance, calibration (Brier scores), and accuracy–fairness tradeoffs.

AI_Fairness_Notebook_Code.ipynb — Jupyter Notebook containing the analysis, model comparisons, and fairness evaluations.

APHA_Poster_References.pdf — References supporting the research and dataset.
